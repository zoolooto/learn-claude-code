s04: 生命周期与 Hook 拦截全景图

展示用户指令从输入、环境上下文注入、LLM 推理、4 大 Hook 拦截点（UserPromptSubmit / PreToolUse / PostToolUse / Stop）到工具分发与闭环回灌的完整执行路径。

"挂在循环上，不写进循环里 —— 扩展点不侵入核心主循环"
Event 01

UserPromptSubmit

用户输入提交后、进入 LLM 前触发。用于校验用户 Prompt、注入当前工作目录（CWD）及环境元数据，不污染用户原始输入。

trigger_hooks("UserPromptSubmit", query)
Event 02 · 核心防护

PreToolUse

工具执行前触发。将 s03 的三道权限闸门（硬黑名单、高危指令、用户二次确认）与调用日志以 Hook 形式挂载。返回非空直接熔断拦截。

blocked = trigger_hooks("PreToolUse", block)
Event 03

PostToolUse

工具执行成功后触发。用于感知工具输出尺寸（大文本告警）、执行耗时度量，或触发自动 git add 等副作用逻辑。

trigger_hooks("PostToolUse", block, output)
Event 04 · 闭环防护

Stop

模型未调用工具准备退出时触发。可打印 Token/调用统计；若返回非空消息，将强制将消息注入对话中驱动 Agent 续跑自愈。

force = trigger_hooks("Stop", messages)
